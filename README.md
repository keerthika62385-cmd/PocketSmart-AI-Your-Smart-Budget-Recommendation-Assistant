# PocketSmart AI: Your Smart Budget & Recommendation Assistant

PocketSmart AI is a beginner-friendly personal finance dashboard built with **HTML, CSS and JavaScript**. It helps users record income and expenses, monitor a monthly budget, visualize spending, and receive rule-based smart recommendations.

## Features

- Monthly income and expense tracking
- Expense categories
- Budget limit and progress indicator
- Balance and estimated savings rate
- Expense-by-category doughnut chart
- Income vs expense bar chart
- Smart recommendations based on spending patterns
- Delete individual transactions
- Browser `localStorage` persistence
- Responsive mobile-friendly interface
- No backend or API key required

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- Chart.js via CDN
- Browser Local Storage

## How to run

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Add income and expenses.
4. Set a monthly budget.
5. Explore the dashboard and recommendations.

## GitHub upload

Create a new GitHub repository named `pocketsmart-ai`, then upload:
- `index.html`
- `style.css`
- `app.js`
- `README.md`

For a stronger portfolio version, you can later add a backend, user authentication, database storage, CSV export, login, and a real AI API.

## Important note

The recommendation engine in this version is **rule-based**, not a live generative AI model. This keeps the project free, safe, and easy to run locally without exposing API keys.
